| [[光圈與景深]] | 入門 | f 值為倒數比值（數字越小光圈開口越大），大光圈進光多且帶來背景虛化的淺景深。 |

| [[測光模式與18灰]] | 入門 | 相機大腦預設全天下都是 18% 中性灰；矩陣適應日常、點測光鎖定逆光主體。 |

| [[直方圖與高光警告]] | 入門 | 拒絕被 LCD 螢幕亮度欺騙的唯一客觀指標；高光溢出狂閃（Blinkies）代表細節徹底死白斷層。 |
| [[片幅裁切與等效焦距]] | 入門 | D40 DX 格式感光元件視角需乘上 1.5x 裁切係數；18-55mm Kit 鏡等效為 27-82.5mm。 |
| [[安全快門法則]] | 入門 | 手持拍攝防手震底線：快門速度分母必須大於「鏡頭實體焦距 $\times$ 1.5」秒。 |
| [[RAW與色彩動態範圍]] | 入門 | JPEG 是煮好的便當，RAW (NEF) 是高寬容度的生鮮食材；白平衡可無損重設，亮暗部拉扯空間極大。 |
