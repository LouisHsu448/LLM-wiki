# Nikon D40 機身規格與光學特點 (Nikon D40 Profile)

> **💡 30秒白話精華（TL;DR）**  
> Nikon D40 發表於 2006 年底，是數位單眼史上的不朽傳奇。它只有 610 萬畫素，但搭載了一顆發色極度濃郁討喜的 **Sony CCD 感光元件**；更擁有現代萬元高階單眼都望塵莫及的 **1/500 秒極速閃光同步快門**！它的輕量（475g）與精簡操作，是新手學習純粹攝影曝光的最佳教具。

---

## 🎯 核心規格與硬體架構

| 硬體組件 | 規格參數 | 對攝影實戰的具體影響 |
| :--- | :--- | :--- |
| **感光元件** | **6.1 百萬有效畫素 CCD** ($23.7 \times 15.6\text{ mm}$，DX 格式) | 原生最低 ISO 200。低感光度下色彩飽和、微對比極佳，具有底片般的高光過渡 |
| **快門系統** | **機械與 CCD 電子快門結合** ($30\text{s} \sim 1/4000\text{s}$，Bulb) | **1/500s 閃光同步快門**，烈日下壓光補光性能極強 |
| **對焦系統** | **Nikon Multi-CAM 530** (3 點相位偵測對焦點) | 中央為十字型感應器；機身無對焦馬達，僅支援 AF-S / AF-I 鏡頭自動對焦 |
| **測光系統** | **420 節 RGB 感測器** | 支援 3D 彩色矩陣測光 II、中央重點測光 (75%集中在8mm圓)、點測光 (3.5mm) |
| **觀景窗** | 眼平五面鏡單反觀景窗 (視野率 95%，放大倍率 0.8x) | 光學即時無延遲取景，內建屈光度調節 (-1.7 ~ +0.5 $m^{-1}$) |
| **螢幕** | 2.5 吋 23 萬畫素低溫多晶矽 TFT LCD | 僅供回放照片與檢視設定，不可用於即時取景 (無 Live View) |
| **重量與儲存** | 空機約 475 克 / SD 記憶卡 (支援 SDHC) | 極致輕巧好攜帶；早期卡槽寫入速度較慢 |

## 📷 兩大不可忽視的硬體神技

### 1. 傳奇 CCD 藍與膚色發色
現代相機普遍採用 CMOS 感光元件以追求高 ISO 抗噪與錄影性能；而 D40 採用的是純靜態拍照特化的 **CCD (Charge-Coupled Device)**。在 ISO 200 的晴天下，D40 直出的天空藍（Nikon Blue）與植物綠色彩厚重濃郁，紅黃色調溫暖通透，是數位攝影愛好者至今熱衷收藏的「直出神機」。

### 2. 1/500 秒電子快門閃燈同步（日光壓光神器）
一般單眼相機受限於上下快門簾幕的物理行程，只要快門快於 1/200s，快門簾就會形成狹縫掃描，導致閃光燈無法照亮全畫面。  
D40 在高於 1/90s 後，機械快門全開，曝光時間由 **CCD 感光元件的電子開關直接切斷**！這使得 D40 無需昂貴的高速同步閃燈，就能以普通外閃或內閃在 **1/500 秒** 釋放閃光，在大太陽逆光下完美壓暗背景並補亮人臉！

## ⚠️ 新手必須清楚的硬體限制

1. **機身拔除 AF 傳動軸（螺絲起子馬達）**：
   - 這是 D40 最重大的硬體妥協（詳見 [[D40_對焦馬達限制與鏡頭選購]]）。無法讓 Nikon 老款 AF / AF-D 鏡頭自動對焦。
2. **無 Live View 即時螢幕取景**：
   - D40 是純粹的「光學單眼」，拍照時必須眼睛貼著觀景窗看進去，背後的 2.5 吋 LCD 螢幕**不能**拿來像手機一樣邊看畫面邊拍照。
3. **高 ISO 噪點極限**：
   - 堪用 ISO 上限為 **ISO 800**，ISO 1600 彩色雜訊顯著，弱光環境需依賴大光圈鏡頭或三腳架。
