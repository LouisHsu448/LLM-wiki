# Nikon D40 對焦馬達限制與鏡頭相容選購指南 (AF-S vs AF-D Lens Guide)

> **💡 30秒白話精華（TL;DR）**  
> 這是所有新手買 D40 最容易踩中的「萬元大坑」：**D40 機身內部沒有自動對焦馬達！** 只有鏡頭名字前面寫著 **「AF-S」** 或 **「AF-I」**（鏡頭屁股自帶超音波馬達）的鏡頭，裝在 D40 上才能半按快門自動對焦。如果你買了老款便宜神鏡「AF 50mm f/1.8D」，裝上去只能手動轉對焦環（手動對焦 MF）！

## 🎯 歷史脈絡與物理結構缺陷

```text
傳統高階機身 (D80/D90/D200)               Nikon D40 入門機身
+--------------------------------+       +--------------------------------+
| 機身內建機械馬達                |       | 為了極致輕量化(475g)與壓低售價  |
| 卡口處有「一字型螺絲驅動軸」   |       | 🚨 徹底拔除機身對焦馬達與驅動軸 |
+--------------------------------+       +--------------------------------+
             |                                       |
    帶動鏡頭機械對焦齒輪                     只能仰賴鏡頭內部自己裝馬達！
```

Nikon 自 1959 年以來維持相同的 F 接環，但自動對焦演進經歷了兩個時代：
1. **機身螺絲傳動時代（AF / AF-D 鏡頭）**：鏡頭內部沒有馬達，完全靠機身伸出一根旋轉螺絲帶動鏡頭齒輪。
2. **鏡頭內建超音波馬達時代（AF-S / AF-I 鏡頭）**：鏡頭內部自帶 Silent Wave Motor (SWM) 寧靜波動馬達，機身僅透過金屬電子接點下達電子訊號。

### 電子測距儀（Electronic Rangefinder）救援
若在 D40 上裝了無法自動對焦的 AF-D 鏡頭手動對焦時：只要鏡頭最大光圈在 **f/5.6 或更大**，觀景窗左下角的綠色圓點 **`●`（合焦指示燈）** 仍能正常工作！手動旋轉對焦環直到 `●` 恆亮，即代表對焦成功。

## 🛒 Nikon D40 新手高 CP 值鏡頭推薦清單

### 1. 標準必備掛機鏡：AF-S DX 18-55mm f/3.5-5.6G ED II
- **定位**：隨機 Kit 鏡，二手價約 1,000 ~ 1,500 元。
- **特點**：極致輕巧（205g），涵蓋等效 27-82.5mm 視角，廣角到中焦通吃（詳見 [[Nikkor_18-55mm_Kit鏡解析]]）。

### 2. 必買大光圈散景神鏡：AF-S DX 35mm f/1.8G
- **定位**：DX 專屬大光圈定焦人像/人文鏡。
- **特點**：等效焦距為標準的 **52.5mm**。擁有 **f/1.8 超大光圈**，能在室內暗處提供充足進光，並在拍攝人像時帶來夢幻的奶油般背景虛化！

### 3. 平價長焦打鳥/望遠鏡：AF-S DX VR 55-200mm f/4-5.6G IF-ED
- **定位**：輕量長焦變焦鏡。
- **特點**：銜接 Kit 鏡焦段，等效達到 **82.5mm ~ 300mm**，自帶 VR 光學防手震，非常適合拍攝遠處寵物、飛鳥與舞台壓縮感特寫。

## ⚠️ 新手最常踩的坑與除錯表

| 錯誤現象 / 直覺誤區 | 背後真實原因 | 快速解法 |
| :--- | :--- | :--- |
| 「網路上大家都推『Nikon 50mm f/1.8D』便宜大碗，我買來裝上 D40 半按快門相機毫無反應」 | 這是最經典的悲劇！50mm f/1.8D 尾部是機械螺絲孔，D40 沒有馬達帶動齒輪 | 購買前務必認明鏡頭正面是否有金色的 **「AF-S」** 字樣；定焦人像請改買 **AF-S 35mm f/1.8G** 或 **AF-S 50mm f/1.8G** |
| 「裝上副廠鏡頭（Tamron/Sigma），無法自動對焦」 | 副廠鏡頭早期也有分內建馬達版與機身對焦版 | Sigma 需認明標有 **HSM**（超音波馬達）；Tamron 需認明有 **Built-in Motor (BIM)** |
| 「裝上老手動鏡頭，相機提示『F--』且快門按不下去」 | 非 CPU 鏡頭無法與機身進行電子通訊，在 P/S/A 模式會鎖定快門 | 將模式轉盤切換至 **M 模式**，手動轉動鏡頭光圈環，並使用直方圖評估曝光 |
